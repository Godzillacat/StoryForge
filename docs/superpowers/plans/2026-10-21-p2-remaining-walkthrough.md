- **环境**：SQLite 备份 API 复制作者库 + `secrets.bin`；后端用副本启动；作者原库未写入，前后哈希一致；验证后删除副本。

## 3. 走查中发现并修复的缺陷

| 缺陷 | 修法 | 提交 |
|---|---|---|
| 批量服务把 `scene_extra` 返回的 `(project, extra)` 元组整个当槽位字典传给运行时，每场都报 `'tuple' object has no attribute 'get'` | 解包后只传 `extra` 字典；测试夹具断言 `extra` 是 dict | `f74d064` |
| 逻辑自检 / 审校在无模型、无问题时顶部提示误报「没有发现问题」 | 先判断 `llm_status`，非 `ok` 时显示降级原因（有规则问题则附数量） | `f74d064` |
| 回写助手看不到伏笔账本，无法命中已有伏笔 | 新增 `foreshadow_ledger` 槽位并接入回写预设 | `9a9ab30` |

## 4. 已知限制

- **零问题的逻辑自检**重载后 `last_checked_at` 为空：与审计问题同一派生方式，修复需给场景加列并迁移。
- **逻辑严格度**：`standard` 与 `strict` 目前行为相同（都保留提示级），只在项目字段上区分；更细的严格度留后续。
- **批量暂停**在场景边界生效：当前场景会跑完；非流式执行，界面没有逐字生成过程。
- **批量不覆盖**已有正文或草稿；作者想覆盖需先手动处理该场景。
- **回写匹配**只做名称/别名精确匹配；模型写出账本外的名字只给警告，不猜。
- **EPUB** 为基础版（无封面、图片、样式模板），未做真机阅读器验证；P5 精修。
- **报告不含锁定状态**：锁定属 P4，尚无数据。
