# 干净 Windows 验收清单（2026-10-24）

> 目标：在一台**没装过 StoryForge、没有本机数据**的 Windows 10/11 上，确认安装包能装、能起、能写、能卸，
> 且卸载不碰作者数据。
>
> 本机（开发机）已经做了**零数据首次启动**的自动验证（见下「本机已验证」），
> 剩下的是**系统级**那一遍：干净机器上的 WebView2、安装权限、快捷方式、卸载体验。

## 0. 准备

- 一台 Windows 10/11 x64（物理机或干净 VM），**没装过 StoryForge**
- 把 `packaging/Output/StoryForge-Setup-0.1.0.exe`（23.3 MB）拷过去
- 确认这台机器有 WebView2 运行时（Win11 自带；Win10 多数已随 Edge 安装）
- 先确认 `%LOCALAPPDATA%\StoryForge` **不存在**（若存在，说明不是干净环境）

## 1. 安装

1. 双击安装包 → 向导（当前是**英文**）→ 一路 Next → Install
2. 记录：
   - [ ] 安装完成，没有 SmartScreen 拦截（未签名时可能出现「更多信息 → 仍要运行」，记录实际文案）
   - [ ] 开始菜单出现 StoryForge
   - [ ] 安装目录（默认 `C:\Program Files\StoryForge`）里有 `StoryForge.exe` 与 `_internal`

## 2. 首次启动（零数据）

1. 从开始菜单启动
2. 记录：
   - [ ] 窗口出现、标题 StoryForge（不是白屏 / 闪退）
   - [ ] 首屏是空项目列表（不是报错）
   - [ ] `%LOCALAPPDATA%\StoryForge\` 自动创建，里面有 `storyforge.db`
   - [ ] 新建一个项目（随便起名）→ 能保存、刷新后还在

## 3. 数据不落在程序目录

- [ ] 安装目录里**没有** `storyforge.db` / `secrets.bin`
- [ ] 关掉程序，重新打开 → 项目还在

## 4. 卸载

1. 设置 → 应用 → StoryForge → 卸载（或开始菜单「卸载 StoryForge」）
2. 记录：
   - [ ] 卸载完成，安装目录被删除
   - [ ] 开始菜单项消失
   - [ ] **`%LOCALAPPDATA%\StoryForge\` 仍然存在，`storyforge.db` 还在**（这是刻意设计：卸应用不删书稿）

## 5. 把结果填回来

把这五节的勾选结果贴回对话即可；有任一项不符，附上截图与 `%LOCALAPPDATA%\StoryForge\` 下的文件列表。
