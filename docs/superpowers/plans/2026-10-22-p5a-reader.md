## 任务

### Task 1 · 整本正文服务与接口

- `export_service.build_book(session, project_id) -> dict`：
  复用 `_ordered_volumes` / `_ordered_chapters` / `_ordered_scenes`，
  只收有正文的章，章内正文按场景顺序用空行拼接（**与 `build_markdown` 逐字一致**）。
  返回 `{project_id, project_name, total_words, volumes:[{id,seq,name,chapters:[{id,seq,title,word_count,content}]}]}`
  其中 `content` 是 Markdown 原文（前端负责渲染）。
- `GET /api/projects/{id}/book`：项目不存在 → 404。
- 测试：只收有正文的章；`content` 与 `build_markdown` 里对应章逐字一致；
  项目不存在 404；空项目返回 `volumes: []`。

**验收**：pytest 绿；用真实项目数据跑一次，章数与字数与导出报告一致。

### Task 2 · Markdown 解析（纯函数）

- `frontend/src/lib/markdown.ts`：
  ```
  type MdBlock =
    | {type:'heading', level:1|2|3|4, text:string}
    | {type:'paragraph', text:string}
    | {type:'quote', text:string}
    | {type:'list', ordered:boolean, items:string[]}
    | {type:'divider'}
  parseMarkdown(text: string): MdBlock[]
  ```
  行内：`**粗**` / `*斜*` / `` `代码` `` → `parseInline(text): MdSpan[]`。
  **HTML 标签原样当文字**（不解释、不执行）。
- 测试（`markdown.test.ts`）：段落 / 标题 / 引用 / 分隔线 / 列表 / 强调 / 内联代码 /
  `<script>` 当文字 / 空输入。

**验收**：vitest 绿；`<script>alert(1)</script>` 渲染成文字。

### Task 3 · 朗读分段（纯函数）

- `frontend/src/lib/speech.ts`：
  ```
  speechChunksOf(blocks: MdBlock[]): string[]   // 去标记、空段跳过、顺序不变
  ```
- 测试：标题与段落都进；引用去 `>`；列表逐项；空段跳过。

### Task 4 · 阅读器页面

- `frontend/src/pages/Reader.tsx` + `App.tsx` 路由 `/read` + 导航「阅读器」。
- 左栏章节树（只列有正文的章，无正文灰显标「未写」）；右栏正文。
- 三套主题（纸张 / 夜间 / 护眼）、字号 4 档、行距 3 档 → `localStorage`。
- 阅读进度：每本书记 `{chapterId, scrollTop}`，重新打开时恢复并给「继续阅读」。
- 检索：输入框 + 结果列表，点击跳到该章并高亮命中。

### Task 5 · 朗读

- 无可用语音时按钮禁用并说明原因。
