# 逻辑链图形化 · 走查记录（2026-10-24）

## 方法

| 手段 | 覆盖什么 | 没覆盖什么 |
|---|---|---|
| 真实 uvicorn（临时数据目录 `.cache/wt-data`）+ 真实 HTTP | 建项目 → 卷 → 章 → 场景 → 写正文 → `GET /api/scenes/{id}/logic-chain` | — |
| 组件级静态渲染：`tsc` 编出组件 → `react-dom/server` → Edge 无头截图 | SVG 的真实几何、颜色、文字截断、空段刻度、横向溢出 | 面板里的开关、ESC、展开层 |
| 代码审查（Task 3 / Task 4 独立审查） | 开关不发请求、默认图形、空态、禁用态、关闭路径 | 真实点击 |

**为什么没有浏览器点击自动化**：本机没有 Playwright，沙箱无外网装不了；Edge 只能无头截图，驱动点击要自己写 CDP 客户端。这一条如实记下 —— 交互部分请作者手点一次（见文末清单）。

## 证据

**1. 真实接口**（正文 6 段，其中 4 段有连接词）

```
paragraphs=6 chain=4 kinds=cause,turn,cause,reveal paras=2,3,4,5
summary={"total":4,"cause":2,"turn":1,"reveal":1}
```

`paragraphs` 覆盖到正文结尾的第 6 段（最后一个命中在 ¶5），这正是加这个字段的理由。

**2. 静态渲染截图**（`.cache/` 下，未入库）

| 文件 | 场景 | 观察 |
|---|---|---|
| `v3-normal.png` | 6 段 6 命中（含 ¶5 两个） | 5 列全见，跨列连线是干净的水平线；¶5 内两个节点用竖直 S 线相连；底部 ¶1–¶5 刻度对齐列中心 |
| `v2-single.png` | 单节点 | 只有节点、没有连线，刻度一枚 |
| `v2-wide.png` | 40 段、¶7 八连击 | 首屏（¶1–¶4）只有刻度没有节点 —— 命中从 ¶7 才开始，要横向滚动才看得到。符合设计（轴不压缩），但初次打开会像空白，见下「已知限制」 |

**3. 修复前的问题（截图抓到的）**

改前跨列边是 `M 184 50 C 216 50, 176 50, 208 50` —— 起止只差 24px，控制点外探到 216/176，渲染成过冲的小圈。根因：列间距 = 192 − 168 = 24，而控制点偏移写死 84。修法：`COLUMN_WIDTH` 192 → 216，控制点取两端中点。修后 `M 184 50 C 208 50, 208 50, 232 50`。

## 已知限制（如实记录）

1. **右栏只有 320px**（`Writing.tsx:1046`），而一列 216px —— 侧栏里只能看到一列多一点。已补「展开」全屏层（同一份数据、不重取），但**展开层本身没有自动化证据**，只有代码审查。
2. **命中起始段靠后时首屏像空白**：轴从 ¶1 开始、不压缩，作者要横向滚动。这是「空段也是信号」的代价；如果作者觉得别扭，后续可做「载入时滚到第一个命中」。
3. 读屏只拿到 `aria-label="逻辑链"`，句子的可读性仍依赖文本视图（切回即得）。已记账为后续。

## 请作者手点一次（2 分钟）

1. 打开任一场有正文的场景 → 逻辑链面板默认是**图形**；
2. 点「文本」→ 列表与以前一致；再点「图形」→ 浏览器 Network 面板**没有新请求**；
3. 悬停任一节点 → 出现全文与「¶段落 · 连接词」；
4. 点「展开」→ 全屏；试 ESC、点「关闭」、双击别的场景（应自动关闭）；
5. 换到一场没有正文的场景 → 显示原有空态，不出现空画布。
