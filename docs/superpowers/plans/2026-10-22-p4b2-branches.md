## 各任务细节

### 任务 1 · 数据层

`SceneBranch`：`scene_id` FK CASCADE、`name`（`uq_branch_scene_name`）、`content`、`draft_content`、`draft_run_id`（FK SET NULL）、`note`。**无迁移**。

### 任务 2 · 服务

- `create_branch`：名称去空白、场景内查重、从主版正文起步。
- `save_branch_body` / `save_branch_draft`：**不拦锁**（作者手工）。
- `adopt_branch_draft`：**拦锁 + 段落锁**，把草稿变成分支正文。
- `discard_branch`：删行。

### 任务 3 · 合并

按设计 §4.1 的七步。复用 `text_service` 的 `_reject_locked`、`_reject_missing_paragraphs`、`_supersede_audit`、`_scene_label` —— 不复制第二份判定逻辑。

### 任务 4 · 分支内生成

复用 `text_service.prepare_generation`（上下文与锁定），但收尾写进分支的 `draft_content`。SSE 事件与主版一致。

### 任务 5 · 历史

开 / 合 / 丢三条。

### 任务 6 · API

十条路由；锁定与段落锁映射 409。

### 任务 7 · 前端

分支面板 + 正文目标切换 + 对比 + 合并确认。正文区顶部固定显示「正在看：主版 / 分支『X』」。

### 任务 8 · 收口

全量测试、`pnpm build`、临时目录走查、浏览器走查、写 walkthrough、同步 CLAUDE.md。
