## 任务

### Task 1 · 样式模板（纯数据 + 纯函数）

- `backend/app/epub_styles.py`：`EPUB_TEMPLATES`（plain / classic）、`template_css(key)`。
- 未知 key 抛 `ValueError`。
- 测试：两套 CSS 非空、含关键选择器；未知 key 报错。

### Task 2 · 重写 `build_epub`

- 结构按设计 §4.2。
- 正文口径继续走 `_chapter_text`。
- 段落不再由服务端套样式；`_chapter_xhtml` 只出语义标记（`<h2 class="chapter-title">`、
  `<p>`、`<section class="volume-title">`）。
- 测试：mimetype 第一条 STORED；container / opf / nav / ncx 齐全；spine 顺序正确；
  CSS 只有一份。

### Task 3 · 卷层级与目录

- 卷扉页 xhtml（仅当该卷有正文）。
- `nav.xhtml` 与 `toc.ncx` 都是两级。
- 测试：nav 里卷是父、章是子；无正文的卷不出扉页也不进目录。

### Task 4 · 封面（服务 + API）

- `backend/app/services/cover_service.py`：`save_cover` / `clear_cover` / `cover_path`。
- 魔数判定 PNG / JPEG；4 MB 上限；临时文件 + 替换。
- `PUT/DELETE /api/projects/{id}/cover`；`GET /api/projects/{id}` 响应加 `has_cover`。
- `build_epub` 接封面：OPF `cover-image`、spine 首页封面、manifest 条目。
- 依赖：`uv add python-multipart`。
- 测试：PNG/JPEG 都能存；伪造扩展名被拒；超限被拒；删除后 `has_cover=false`；
  有封面时 OPF 结构正确；无封面时没有封面页。

### Task 5 · 模板参数

- `GET /api/projects/{id}/export?format=epub&template=classic`；未知 400。
- 测试：两套模板产出的 CSS 不同；未知模板 400。
