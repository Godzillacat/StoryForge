# StoryForge 前端交互手点清单（重塑收口后）

- 日期：2026-11-02
- 适用版本：前端重塑完成后的 master（13 页全部新语言）
- 用途：UI 交互**没有自动化测试**（本机无 Playwright、无外网），这张清单供作者逐项手点。每项都给出「操作 → 预期 → 重点看什么」，结果列留空供记录。
- 建议：在**临时数据目录**或先建项目快照后再点；清单里的新建 / 删除 / 采纳会真实写库。

## 0. 前置与判据

- 控制台全程 **0 ERROR**（warn 可以记录）。
- 1440×900 与 1280×800 各走一遍；页面无横向滚动、无内容被裁切。
- 键盘：Tab 能到所有可交互元素，焦点环可见；Dialog 可 ESC 关闭。
- 系统开启「减少动态效果」后，过渡与骨架微光应停止。

## 17. 重点风险（优先看这些）

1. **切项目竞态**：把网络调慢（DevTools throttling），在写作台 / 章节页快速连续切项目，确认旧响应不会写进新项目。
2. **在途请求与页签**：写作台四页签里启动 A/B 或批量，切到别的页签再回来，确认请求没被打断。
3. **分支派生的 `window.prompt`**：在 pywebview / WebView2 外壳里是否被拦截；若被拦截，要改成内联输入。
4. **双击保存**：人物状态、关系、单价等快速双击，确认不会撞唯一约束 500。
5. **localStorage 损坏 / 清空**：手工写坏 `storyforge.*` 值，确认静默回落默认值。
6. **后端停机 / 慢响应**：页面给出可读中文，不白屏、不误报「成功」。
7. **朗读**：不同 Windows 语音包下开始 / 暂停 / 继续；切章或离开页面必须停。
8. **导出 EPUB**：至少用一个真实阅读器打开，确认目录、封面、样式。
9. **批量暂停**：在场景边界暂停 / 继续；失败后「重试」是否包含 cursor 之后未处理场景。
10. **A/B 409**：本场已有未处理组时再建，必须被拒而不是静默删旧组。

## 18. 如果要自动化（优先级建议）

本机目前没有 Playwright，自动化需要先安装（含浏览器下载）。建议顺序：

1. **P0**：项目切换 + 写作台生成 / 采纳 / 段落锁（最高频、最容易回归）。
2. **P0**：A/B 建组 → 采纳、分支新建 → 合入（一次提交语义）。
3. **P1**：审校 / 逻辑自检 / 回写（无模型时走降级分支，不需要真实调用）。
4. **P1**：章节树 CRUD 与锁定继承。
5. **P2**：模型与费用表单、工作室版本保存 / 回滚。
6. **P2**：阅读器检索与进度记忆（朗读因系统语音而异，建议只测不支持分支）。

> 自动化只覆盖确定性路径；模型输出质量与真机 TTS 仍需人工看。
